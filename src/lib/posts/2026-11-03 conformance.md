All conformance repositories moved to a dedicated GitHub organisation, [jam-conformance](https://github.com/jam-conformance). _Disclaimer: This is not the official auditing process._

A new [jam-crypto repository](https://github.com/jam-conformance/jam-crypto) provides test vectors for Bandersnatch, Ed25519 and Reed-Solomon. It includes a Python reference implementation compatible with reed-solomon-simd.

P.S. CoreVM and the JAM tooling will also be moving to public repositories, in the near future.
